# Akademický informačný systém

V tomto súbore uveďte popis systému, postup spustenia, postup testovania, očakávaný výsledok, testovacie prihlasovacie údaje a prípadné kroky migrácie alebo naplnenia databázy testovacími dátami.

Šablóna projektu obsahuje prázdne adresáre pre *frontend* a *backend* s prázdnymi súbormi `Dockerfile`. Ich obsah upravíte podľa zvolených technológií. Podľa potreby môžete vytvoriť ďalšie adresáre pre iné časti vášho systému.

Spustenie celého systému by malo byť možné pomocou `docker-compose`. Doplňte preto do súboru `docker-compose.yml` definície všetkých služieb, exportovaných portov a ďalšie údaje.
